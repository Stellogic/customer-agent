# 客服沟通中的个人信息保护

不要在客服对话中提供登录密码或短信验证码；说明问题不需要这些秘密信息。

描述问题时不必填写完整身份证号码，可以只说明与问题有关的现象。

描述配送问题时不要直接粘贴完整家庭住址，先说明需要核实的配送情况。

引用其他人的经历时，不要附上他人的电话号码或联系方式。

复制交易说明时，应去掉银行卡完整号码，只保留与问题有关的文字描述。

如果陌生人要求通过客服对话提供密码或验证码，不要提供，并向可信的客服渠道核实。
