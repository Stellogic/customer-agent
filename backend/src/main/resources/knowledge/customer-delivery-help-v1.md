# 配送问题的信息补充指南

物流信息长时间没有变化时，可以在当前工单说明最后一次看到的物流节点和大致时间，方便客服核对。

页面显示签收但没有找到包裹时，可以先查看代收点，并询问同住人员是否代收；仍未找到时在当前工单说明情况。

包裹外包装破损时，可以在工单描述破损位置以及商品是否受到影响，不必在文字中填写完整住址。

同一配送问题有新进展时，优先在原工单补充，便于客服连续了解经过。

这里的配送指南只说明一般处理方法；当前订单和物流状态由客服核对后的工单回复说明。

物流节点没有更新不等于确认丢件，是否丢失仍需要核实，不能仅凭更新时间推断。
