# 物流延迟

物流节点超过承诺时间没有更新时，先核对订单与物流的当前权威状态，再向客户说明已确认的个案事实。知识条目只解释一般处理原则，不替代 Spring 返回的订单、物流或补偿结果。

客服可以引用当前条目的标题、更新时间和具体片段；如果事实不足或规则与当前订单冲突，应保留问题并转人工核验。
