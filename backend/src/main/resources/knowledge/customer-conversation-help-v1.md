# 工单沟通与回复说明

描述问题时，先说明遇到的现象、发生的大致时间以及希望客服帮助核实什么，便于理解诉求。

客服询问补充信息时，请围绕问题补充自己知道的情况；不确定的内容可以直接说明不确定。

发现之前描述有误时，可以在原工单中明确说明哪部分需要更正，以及更正后的信息。

回复中的知识来源标题和更新时间用于说明一般规则的出处，不代表已经核实了当前订单的事实。

一般知识说明与当前工单已核验的事实不一致时，应以当前工单已核验的业务事实为准。

资料不足时，客服可以说明暂时无法确定或继续询问；这不表示问题已经解决。
