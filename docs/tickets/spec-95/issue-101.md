## What to build

在客户、客服和审批三个页面切片都已经各自完成行为测试、生产构建和聚焦浏览器验证后，执行跨身份总验收。统一检查视觉语言、桌面布局、可访问性、身份与数据投影隔离、路由延迟加载、客户首屏 bundle 边界和仓库完整门禁。

本票据是集成验证与小范围收口票据，不承担客户、客服或审批页面的大规模返工。如果发现某个前置切片未满足自身验收标准，应回到相应前置票据修复或另建明确票据，而不是在本票据吸收未完成实现。

## Acceptance criteria

- [ ] 未登录、客户、仅客服、仅审批人和双角色内部工作人员的真实浏览器场景全部通过。
- [ ] 客户界面壳与内部界面壳视觉一致但导航和数据投影保持隔离，双角色选择页不预读业务数据。
- [ ] 客户、客服和审批页面在约定桌面视口下的配色、字体层级、空间节奏、状态组件和交互反馈一致。
- [ ] 键盘遍历、可见焦点、表单标签、非纯颜色状态表达、确认对话框焦点管理和减少动态效果支持通过跨页面检查。
- [ ] Session 失效、主体替换、客服工单分配撤销和审批租约撤销后的受保护内容均立即不可见。
- [ ] 客户首屏静态闭包不包含内部工作台业务模块，既有 bundle 证据继续通过。
- [ ] 真实浏览器全套验收、前端完整检查、生产构建、bundle 证据和仓库根级完整门禁全部通过。
- [ ] 验收报告明确区分页面切片既有证据与本票据新增的跨身份、跨页面和 bundle 总验证证据。
- [ ] 本票据只接受小范围一致性修正；不存在把前置页面重做或补齐其缺失行为测试的隐性范围扩张。
