## What to build

建立高保真原型所定义的视觉基础，并立即把它用于正式应用的全局加载、错误、403、404、断线与重新同步体验。基础能力仅围绕本票据和后续已明确页面立刻需要的配色、字体层级、间距、阴影、状态语义与交互反馈进行提取；不建设独立于真实页面的空泛设计系统。

保持现有路由、身份恢复、页面 capability、受控返回地址和错误语义不变。状态必须同时通过文字、图标和颜色表达，支持键盘焦点与减少动态效果设置。

## Acceptance criteria

- [ ] 森林绿、深军绿、米白、鼠尾草绿、衬线标题、无衬线正文、克制圆角与阴影形成统一且可复用的视觉基础。
- [ ] 只提取会在本票据全局状态或已明确后续真实页面中立即使用的组件与样式；不存在未被真实页面消费的通用组件库或大而全主题层。
- [ ] 全局加载、路由错误、403、404、断线与重新同步状态采用统一视觉语言，并保持既有 HTTP、路由和授权行为。
- [ ] 403 文案不泄露业务数据或内部 capability 名称；404 不增加资源存在性线索。
- [ ] 状态不只依赖颜色，键盘焦点清晰，动画尊重减少动态效果设置且不会延迟撤权清屏。
- [ ] 行为测试从用户可见结果验证全局状态，不绑定组件文件数量、内部 state 或 CSS 类名。
- [ ] 前端格式检查、Lint、类型检查、行为测试和生产构建通过。
- [ ] 使用聚焦浏览器验证桌面视口下的全局状态与关键键盘行为，留下可复现证据。
