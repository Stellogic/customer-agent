## What to build

在 Agent 或工具失败、客户要求人工或问题超出自动识别能力时创建受理协助请求，让客服在独立队列中帮助确认订单和拟建工单集，但不提前获得正式工单的调查、补偿或审批权限。

## Acceptance criteria

- [ ] 受理协助请求与客服工单使用不同业务身份、状态、队列和权限。
- [ ] 客服在领取前只看到裁剪摘要，领取后只能查看完成受理确认所必需的信息。
- [ ] 客服可以协助修正订单候选和拟建问题，但最终仍需要客户确认后才创建正式工单。
- [ ] 协助阶段不能读取完整订单详情、形成补偿提案、发送工单公开回复或执行工单动作。
- [ ] 领取、释放、过期、重新分配和完成在刷新、重登和 SSE 断线后保持权威一致。
- [ ] Agent 或工具恢复不会越过已建立的人工责任，也不会产生双重确认。
- [ ] 内部受理队列与详情同步复刻原型队列语言，覆盖桌面、窄屏、loading、empty、error 和权限撤销状态。
