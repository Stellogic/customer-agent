## What to build

建立仓库内版本化中文 Markdown 知识目录，真实解析和稳定分段后提供内部词法检索与查看页面。查看、检索、版本和引用必须连接真实数据；编辑、审核和发布入口只显示“开发中”。

## Acceptance criteria

- [ ] 知识条目要求稳定 id、标题、版本、更新时间、适用范围和正文，缺失或重复元数据明确失败。
- [ ] 分段结果具有稳定 chunk id、条目标识、版本、源文件和片段位置，相同输入可复现。
- [ ] 只有允许发布状态、当前版本和适用范围的条目进入普通检索；旧版本仍可审计但不误作当前答案。
- [ ] 内部人员可以执行真实关键词检索、查看条目、版本、适用范围和具体引用片段。
- [ ] 客服与其他内部身份的知识可见性遵循 capability，不能仅靠隐藏菜单授权。
- [ ] 内容更新、删除、重复索引和失败重建具有明确一致性与可恢复语义。
- [ ] 编辑、审核、发布和回滚控件可以复刻原型，但点击只反馈“开发中”，不写入或伪造成功。
- [ ] 内部知识页面覆盖桌面、窄屏、loading、empty、error、无结果、旧版本和开发中状态。
