## What to build

交付独立可访问的状态画廊以及 403、404 页面，使设计评审者能够在不制造真实业务副作用的情况下复核全局状态语言、身份边界和恢复反馈。

## Non-goals

- 不重写客户受理、工单对话、客服处理、审批或知识检索流程。
- 不把受保护业务数据加载到 403 或 404 页面。
- 不在本票补做客户壳或内部壳的剩余导航入口。

## Acceptance criteria

- [ ] 新增并完成 /states 状态画廊，覆盖首次 Loading skeleton、Empty、保留旧数据的 Error、403、404、实时连接断开、正在重新同步、审批租约过期、操作成功和操作结果未知。
- [ ] 完成独立 /403 与 /404 路由，依据当前身份提供准确说明和安全返回入口，且不请求或展示受保护业务数据。
- [ ] 状态示例复用正式应用的森林绿、米白、字体、间距、组件和反馈语言，不建立只在画廊中存在的伪设计系统。
- [ ] 所有示例不发送业务写请求、不伪造发送、领取、审批、补偿或知识发布成功。
- [ ] 真实 Chromium 验收覆盖桌面、窄屏、键盘焦点与基础屏幕阅读器语义，并保存逐项映射的视觉证据。
