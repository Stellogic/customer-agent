## What to build

让客户直接用自然语言开始一次单订单、单问题受理。Agent 根据当前客户可见的订单摘要提出订单候选和问题理解，低置信度时以自然语言澄清；客户明确确认后，Spring 才创建正式客服工单。

## Acceptance criteria

- [ ] 客户入口不要求先选择问题类型，也不强制先从订单列表选择订单。
- [ ] Agent 只能从 Spring 返回的当前客户可见订单摘要中提出订单候选，候选不授予完整订单读取或副作用权限。
- [ ] Agent 以自然语言表达问题理解；低置信度时询问“你说的是不是……”并允许客户纠正。
- [ ] 客户可以用自然语言或快捷按钮确认，两者使用同一幂等业务语义。
- [ ] 确认前不存在正式客服工单，也不启动首次响应或解决时长目标。
- [ ] 确认时重新校验订单权属；猜错、越权、已变化或不存在的订单不能创建工单。
- [ ] 确认成功只创建一张属于已确认订单和问题的工单，并启动独立 Agent 处理代次。
- [ ] 客户受理 UI 复刻原型的帮助中心视觉语言，同时提供桌面、窄屏、loading、empty、error 和确认状态。
