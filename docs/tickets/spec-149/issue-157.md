## What to build

让客户与内部工作人员按订单工单组查看多张独立客服工单，并在统一创建后立即并行处理。订单分组只用于导航和最小协调，不合并状态、负责人、对话、补偿或审批边界。

## Acceptance criteria

- [ ] 客户订单总览按订单显示工单、问题类型、状态、处理模式、受控进度和待客户事项。
- [ ] 内部工作台按订单分组展示工单，但领取一张不会领取或授权同订单其他工单。
- [ ] 同一批创建的工单无需用户逐张打开即可启动独立 Agent 处理代次。
- [ ] 每张工单的公开沟通、生命周期、SLO、负责客服、补偿和审批保持独立。
- [ ] Agent 只能读取同订单其他工单的问题类型、状态、待办动作和补偿流程存在性。
- [ ] 同订单工单摘要不包含完整对话、自由形式摘要、内部记录或跨工单写权限。
- [ ] 并行处理和同订单事实更新在真实 PostgreSQL 并发下不会交叉发送消息或覆盖状态。
- [ ] 客户与内部订单分组 UI 同步覆盖桌面、窄屏、loading、empty、error、部分工单失败和多待办状态。
