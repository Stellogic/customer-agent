## What to build

让 Agent 从同一订单的一次自然语言描述中识别多个独立问题，逐项澄清不确定理解，并在客户一次确认后原子创建多张独立工单和一份共同受理记录。

## Acceptance criteria

- [ ] Agent 能把“包裹未收到且疑似重复扣款”等描述拆成同一订单下的多个受控问题类型。
- [ ] 每个低置信度问题都先以客户可理解的语言澄清，未经确认的问题不能进入拟建工单集。
- [ ] 确认界面明确展示订单、每个拟建问题及将创建的工单数量，不要求客户逐项重新描述。
- [ ] 一次自然语言确认或快捷确认原子创建全部新工单；任何失败一张都不创建。
- [ ] 每张工单只有一个订单和一个问题，并拥有独立状态、处理模式、Agent 处理代次和公开沟通。
- [ ] 同一次确认形成一份不可变共同受理记录，各工单通过稳定引用关联，不复制可漂移正文。
- [ ] 幂等重试不会重复创建部分或全部工单，冲突返回可恢复的权威结果。
- [ ] 对应多问题确认 UI 同步交付桌面、窄屏、loading、empty、error、部分识别和确认失败状态。
