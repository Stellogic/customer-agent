## What to build

在 `HUMAN` 处理模式下，让当前负责客服请求工单总结、知识检索、政策查询和回复草稿。客服可以查看内部知识版本、标识与引用片段，但辅助输出必须人工审阅后发送，不能产生公开消息或业务副作用。

## Acceptance criteria

- [ ] 只有当前负责客服可以对其工单发起 Agent 辅助；领取撤销后立即失去请求和结果访问权。
- [ ] 辅助输入限于当前工单授权投影、近期公开消息、可重建摘要、调查事实和允许的知识范围。
- [ ] 总结、知识检索、政策查询和回复草稿使用明确的辅助类型与稳定请求身份。
- [ ] 客服可以查看知识标题、版本、内部标识、引用片段和适用范围，不显示模型思维链、prompt 或原始检索载荷。
- [ ] 回复草稿不会自动进入公开沟通；客服编辑并显式发送时仍经过人工回复权限与幂等校验。
- [ ] Agent 辅助不能切换处理模式、修改工单、形成或提交补偿、审批或执行任何动作。
- [ ] 无答案、知识冲突、索引失败或模型失败产生受控辅助失败，不影响人工继续处理。
- [ ] 客服详情中的 AI 摘要、建议、引用和 composer 复刻原型区域，并覆盖桌面、窄屏、loading、empty、error 和撤权清屏。
