## What to build

把既有有预算工具循环提升为事实充分契约：Agent 自主选择调查路径和证据组合，并提交结构化证据集合及证据与结论的适用关系；Spring 不编排完整调查流程，只验证权威边界和风险必需事实。

## Acceptance criteria

- [ ] Agent 可以在同一受支持场景中选择不同合法工具顺序，测试不要求唯一 DAG。
- [ ] Agent 结论包含结构化证据引用和每项证据对结论的适用关系，不保存自由形式思维链。
- [ ] Spring 校验证据属于当前工单和处理代次、来源获授权、仍在时效内且不存在已知冲突。
- [ ] Spring 按版本化风险场景校验不可缺失事实，但不向 Agent 返回完整调查步骤脚本。
- [ ] 模型主观置信度、证据数量或完成固定工具清单都不能单独构成事实充分。
- [ ] 越权证据、未知来源、过期事实、冲突事实和缺少风险必需事实均被拒绝并产生受控结果。
- [ ] Agent 仍受行动数、重复无进展、墙钟、token、费用和供应商尝试预算约束。
- [ ] 内部可观察性只保存动作类型、结果、证据引用、受控理由码和预算，不保存原始工具载荷或模型独白。
- [ ] 当前物流场景通过真实 LangGraph、Spring 和 PostgreSQL 证明至少两条合法调查路径可得到相同安全业务结论。
