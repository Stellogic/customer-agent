## What to build

在单张客服工单上完成持久化领取和人工公开回复。负责客服责任由 Spring 管理，不因页面切换、刷新、重新登录或 SSE 中断而丢失；未领取者或旧领取者不能查看详情或发送消息。

## Acceptance criteria

- [ ] 同一工单同一时刻至多一名负责客服，并发领取只有一个成功。
- [ ] 领取后获得完整工单授权投影，领取前仍只显示裁剪队列摘要。
- [ ] 页面切换、刷新、重新登录和 SSE 中断后，负责客服责任和工单详情仍从 Spring 恢复。
- [ ] 释放、交回 Agent、解决、关闭、管理员重分配或权限撤销会终止旧责任和详情访问。
- [ ] `HUMAN` 处理模式下只有负责客服可以向客户发送公开回复。
- [ ] 公开回复具有稳定消息身份和幂等语义，响应不明确时可查询权威结果而不是鼓励重复提交。
- [ ] Agent 在 `HUMAN` 模式下不能直接联系客户或产生业务副作用。
- [ ] 客服队列和工单详情复刻原型的摘要、负责人、时间线、对话与 composer，并覆盖桌面、窄屏、loading、empty、error 和撤权清屏。
