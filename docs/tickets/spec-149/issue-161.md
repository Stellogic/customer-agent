## What to build

把自主调查从物流延迟扩展到物流异常、支付与退款、订单操作与规则及其他问题，并允许 DeepSeek 生成有依据的自然回复。业务事实、金额、资格和时效承诺仍由 Spring 权威字段控制。

## Acceptance criteria

- [ ] 四类受控问题类型均有明确授权能力、最小结构化工具结果和失败转人工路径。
- [ ] 物流停滞、签收未收到、疑似丢件、重复扣款、退款状态、地址或取消规则及 OTHER 均有代表性合成场景。
- [ ] Agent 基于事实充分结果自主形成自然解释，不被限制为少数固定句式或完整预编排流程。
- [ ] 订单、物流和支付事实只能来自授权调查事实；金额、资格和时效只能引用 Spring 权威结构化结果。
- [ ] 回复发送前检查当前代次、处理模式、证据范围、越权承诺、无依据事实和敏感信息。
- [ ] 一次受控修正仍不安全、工具失败、证据不足或场景不支持时停止回复并转人工。
- [ ] DeepSeek 正式模式失败不回退 fixed fake；确定性 CI 通过同一产品契约运行受控模型响应。
- [ ] 客户和负责客服看到符合各自授权投影的结论与依据，审批人视图不因此扩大。
- [ ] 每种问题的页面状态同步覆盖桌面、窄屏、loading、waiting、error、转人工和明确结论。
