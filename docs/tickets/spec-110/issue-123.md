## What to build

将当前工单和处理代次范围内的合成客户描述、公开沟通和必要调查结果最小化后交给客户沟通模型，并使用可编程供应商替身覆盖意图判断、必要澄清、调查摘要和受约束自动回复，不调用真实 DeepSeek。

## Acceptance criteria

- [ ] 覆盖自然语言意图、必要澄清、无需补偿、等待人工审批和转人工等回复意图。
- [ ] 客户文本中的提示注入、退款命令或越权要求始终被当作不可信业务数据。
- [ ] 回复只引用授权证据，不宣布未批准金额、最终执行结果或无法保证的响应时间。
- [ ] 模型拒绝、无效输出、不确定或安全校验失败时不发送猜测性回复并转人工。
- [ ] 自动回复进入现有公开消息系统，并通过离线全栈和完整规范化门禁。
