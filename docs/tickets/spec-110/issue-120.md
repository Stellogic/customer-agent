## What to build

让调查模型每轮选择一个受控下一行动，执行类型化能力后读取规范化结果并继续，直至请求澄清、提交结论或转人工。先使用确定性行动模型验证自主编排、资源预算和审计边界，不调用真实 DeepSeek。

## Acceptance criteria

- [ ] 模型只能产生允许的下一行动、请求澄清、提交结论或转人工。
- [ ] 每个处理代次具有最大行动数、墙钟时间、token、费用、供应商尝试和重复动作预算。
- [ ] 重复无进展、未知行动、工具反复失败或预算耗尽都会显式转人工。
- [ ] 调查行动记录只保存动作类型、受控事实或证据引用和业务结果，不保存思维链或原始 payload。
- [ ] 测试允许不同合法工具顺序，只断言最终结果、证据、安全不变量和预算，并通过完整门禁。
