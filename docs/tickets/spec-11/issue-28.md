## What to build

完成已解决客服工单的关闭等待期语义。客户在 72 小时内就同一问题提出异议时重开原客服工单；等待期结束或回复属于不同问题时保留稳定历史并创建关联的新客服工单。

## Acceptance criteria

- [ ] 客服工单进入 RESOLVED 后开始连续 72 个自然小时的关闭等待期；该时段不累计解决时长。
- [ ] 恰好连续 72 小时且无同一问题客户异议时自动转为 CLOSED；内部记录和自动通知不会重开或延迟关闭。
- [ ] 等待期内同一问题的客户公开回复把原客服工单重开为 INVESTIGATING，并延续原解决时长、剩余预算和首次响应事实。
- [ ] 重开后的处理遵守当前处理模式和客户人工偏好；不得自行恢复已撤销的旧 Agent 处理代次。
- [ ] CLOSED 客服工单不能直接重开；关闭后的回复创建关联新客服工单，原工单历史保持不变。
- [ ] 等待期内明显不同的问题同样创建关联新客服工单，而不是污染原工单公开沟通和业务状态。
- [ ] 客户消息使用稳定身份去重；关闭任务与回复真正并发时，只产生一种合法结果，不会既重开又创建重复新工单。
- [ ] 可控时钟测试覆盖 72 小时前一瞬、恰好边界、边界后一瞬、重复调度、同问题/不同问题以及关闭/回复并发。
