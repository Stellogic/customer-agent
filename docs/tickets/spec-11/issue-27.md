## What to build

让 APPROVAL_VIEW 在断线时安全恢复，并在审批责任结束时同时撤销现有读写请求和正在连接的 SSE。旧页面、旧租约与旧游标不能演变为持续的提案或客服工单访问权。

## Acceptance criteria

- [ ] APPROVAL_VIEW 以补偿提案版本和当前审批租约为范围，拥有独立投影形状、epoch、sequence、快照和 SSE 端点。
- [ ] 建立连接、重放每个事件和投递实时事件时均重新校验当前审批人、租约 token/version、服务器时间、提案版本及状态。
- [ ] 租约过期、显式 release、重新分配、提案替换、提案到期、批准或驳回都会终止既有 SSE 并使后续快照与命令拒绝。
- [ ] 权限撤销后，界面立即移除审批证据和操作并返回队列；旧页面刷新、浏览器历史、旧游标和旧事件不能恢复访问。
- [ ] 重复、旧序号、缺口、epoch/view/schema 不兼容、裁剪历史和非法 payload 按契约触发忽略或完整快照重置。
- [ ] 审批流只含租约和决定所需白名单事件；不包含完整客服工单、执行恢复能力、Agent 内部标识或原始证据 payload。
- [ ] 审批人不能通过审批视图调用执行、重试、对账、撤销补偿或其他角色 API。
- [ ] 自动化验收覆盖连接存续期间的租约到期/释放/替换/决定、断线重连、两个审批人竞争和授权撤销后的旧页面操作。
