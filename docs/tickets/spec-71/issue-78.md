## What to build

收紧所有人工身份的 Session、跨标签页退出和 SSE 生命周期，使主体替换、退出、无活动过期或资源授权撤销后，浏览器缓存与长连接都在明确时间内停止使用旧授权。

## Acceptance criteria

- [ ] 三十分钟无活动后 Session 失效，后续 API 返回 401，前端回到与目标 shell 对应的登录入口。
- [ ] 客户与内部工作人员之间改用另一主体登录时替换旧 Session，不叠加身份、角色或缓存。
- [ ] 一个标签页退出后通过同源跨标签页通知，使其他标签页立即关闭 SSE 并清除身份与主体相关业务缓存。
- [ ] 服务端 Session 失效是权威结果；跨标签页通知丢失时，其他标签页在下一次请求或 SSE 重连时仍收敛为未登录。
- [ ] 每条人工身份 SSE 单次连接最长六十秒，客户端自动重连，每次重连重新验证 Session、角色和具体资源授权。
- [ ] 客服分配撤销、审批租约失效、提案版本变化或客户归属不匹配时，重连不能继续获得旧投影。
- [ ] 登录、退出和 Session 更新后重新取得 CSRF token，旧主体 token 不能用于新主体写操作。
- [ ] 登录成功、登录失败、退出和 Session 过期进入结构化安全日志，不写入业务审计事件。
- [ ] 安全日志不包含密码、Session cookie、CSRF token 或完整敏感业务 payload。
- [ ] 浏览器、API 和 SSE 测试证明六十秒是异常失联时授权陈旧窗口的上界，而不是只断言客户端存在定时器。
