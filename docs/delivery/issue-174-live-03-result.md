从既有 runner 日志提取的 [三个聚合检查点](issue-174-live-03-checkpoints.json) 补齐了阶段边界：L174-01 后、L174-02 前均为两个代次、10次尝试、5881 token、两次 SCHEMA_MISMATCH；L174-02 失败后增加一个代次、6次尝试、3341 token 和一次 BUDGET_EXHAUSTED。因此两次 schema 失败属于第一场景建单后的调查，预算失败属于第二场景新增调查。仍未取得具体 schema 字段或循环预算剩余值。
