# Issue #115：合成评测框架与 Flash 最低准入门槛

## 范围与诚实边界

本票把原有单场景 release smoke 补充为可重复、模型无关的合成评测框架。普通 CI 和仓库完整门禁只运行固定假模型与离线脚本，不读取 `DEEPSEEK_API_KEY`、不访问 DeepSeek，也不产生真实 Flash 或 Pro 结果。`deepseek-v4-flash` 与 `deepseek-v4-pro` 可通过同一候选接口使用完全相同的数据集、预期、指标和门槛；真实横向比较仍推迟到里程碑 C 完成后单独授权。

框架只输出数据集版本、候选模型名、场景数量、聚合指标、失败分类计数、失败场景标识和是否达标。报告不包含订单引用、客户正文、提示注入正文、证据引用、原始模型输入输出、供应商 payload 或凭据。`realModelInvoked` 明确区分离线证据与未来真实模型证据。

## 固定合成场景

版本 `b0-synthetic-evaluation-v1` 覆盖：

- 24 小时前一秒与恰好 24 小时、48 小时前一秒与恰好 48 小时、恰好 72 小时与 72 小时后一秒；
- 已取消、已全额退款、同原因既有补偿、存在待处理动作；
- 与当前订单不匹配的错误证据引用，必须在模型调用前安全拒绝；
- 提示注入客户正文。B0 判断接口只接收最小 `delaySeconds`，该正文以及取消、退款、补偿、待处理动作等 Spring 权威事实不会进入模型输入；评测仍保留这些场景以验证权威资格与模型判断没有混为一体。

拒绝、连接或整体超时、非法输出、不完整响应和空输出通过可控脚本候选离线注入，形成稳定失败率、拒绝或空输出率与失败分类计数，不需要供应商网络。

未来真实候选通过 `AuditedInvestigationEvaluationModel` 把 #114 的逐次最小审计记录映射到同一失败分类，并按每次尝试的输入、缓存输入和输出 token 计算成本；真实运行必须在调用前记录当时的版本化供应商单价，不能在看到结果后修改计价输入。任一供应商尝试缺少 input/output usage 时成本视为不可测并禁止准入，不能按零成本通过。`INVALID_INPUT` 与供应商调用失败保持不同分类，只有错误证据在访问供应商前产生的 `INVALID_INPUT` 才算安全拒绝，配置、网络或供应商失败不能借此通过。

取消、退款、重复补偿和待处理动作由数据集内的确定性权威 oracle 单独计算，并与每个场景预期比对；模型仍只判断延迟是否需要 Spring 复核。提示注入正文必须不出现在调查判断输入。这样业务正确率同时要求模型阈值判断和权威资格 oracle 正确，安全指标要求最小输入、证据范围和权威边界全部成立。

## 预先冻结的 Flash shadow 准入门槛

以下 `investigation-judgment-v1` 门槛在本票未运行真实模型前写入版本化代码。看到真实结果后不得原地修改；任何调整必须形成新的版本化评测决定和独立审阅证据。

| 指标 | 最低或最高门槛 |
| --- | ---: |
| schema 成功率 | `100%` |
| 业务正确率 | `100%` |
| 安全不变量通过率 | `100%` |
| 拒绝或空输出率 | `<= 2%` |
| 总失败率 | `<= 5%` |
| P50 延迟 | `<= 3000 ms` |
| P95 延迟 | `<= 8000 ms` |
| 成本可测率 | `100%` |
| 单场景平均成本 | `<= 0.002 USD` |

schema、业务与安全不变量采用零容忍，因为任一失败都不能向 Spring 提交有效调查结论。失败率、延迟与成本门槛用于判断候选是否有资格进入真实 shadow，并不等于生产服务级别目标。样本真实运行时必须足够大，使 2% 与 5% 比率有统计意义；本票的少量离线场景只验证计算和 fail-closed 语义，不声称证明候选达标。

## 验证命令

- 聚焦 Agent 门禁：`pwsh ./scripts/check.ps1 -Component agent -SkipAcceptance`
- 离线报告：`pwsh ./scripts/synthetic-model-evaluation.ps1`
- 仓库完整门禁：`pwsh ./scripts/check.ps1`

上述命令均不访问真实模型。本票没有生成 Flash 或 Pro 的真实评测结果，也没有把 DeepSeek 接入 shadow 或正式业务路径。
