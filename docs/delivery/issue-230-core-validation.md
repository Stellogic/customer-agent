## 预算与计量边界

受理操作数不等于供应商尝试数：普通单订单确认不再重新理解已确认内容，但推进下一订单仍可能发生新调用。精确计量必须来自调用证据，不能根据操作数推算。

现有 `costMicros` 采用美元程序估算；新的人民币预算不得与它直接相加。核心报告应分别列实际 usage、按冻结价格计算的程序估算、供应商结算和未结算预留。供应商结算不可获得时保持未知。

2026-09-07 核对的 [DeepSeek 官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)列出 Flash 0731 高峰输入未命中 3 元/百万 token、输出 9 元/百万 token。候选预算策略按高峰、不计缓存折扣预留。请求 JSON 字节数两倍加余量仅是工程预留，无法证明供应商内部组装的数学上界；不得称为精确计费。实际 usage 以 [供应商返回值](https://api-docs.deepseek.com/zh-cn/quick_start/token_usage/)为准。

实现仅服务冻结核心诊断：跨运行保留的宿主账本共享本次授权，固定旁路文件锁保护原子更新。已通过模块级并发预留、未知 usage 保留、已知 usage 释放差额与超预留停止测试；四类模型实际 POST 前的接入仍待实现与验证，不能据模块通过宣称真实请求已受保护。所有重试必须计入同一上限。未知 usage、超预留或重启遗留未完成请求停止后续付费请求，保留预留。账本不能只存在于会随 Compose 清理的数据库卷中。
