后续获准接线时，同一 HUMAN 辅助请求把当前问题、授权调查事实及上述片段交给**负责草稿生成的同一次 DeepSeek 调用**，输出明确的 `SUPPORTED` 或 `INSUFFICIENT_INFORMATION` 决定，并同时生成有依据草稿或不足说明及必要追问。默认没有独立的充分性调用、额外判断模型或 reranker。新调用不是本轮已实现能力。

生成输出的最小语义如下；实际 wire schema、prompt、模型版本和总输出预算须在真实验证前冻结，本轮不伪造现行 API：

- `SUPPORTED`：草稿/说明与采用的授权引用绑定；个案订单、支付、物流、资格、金额和时效来自 Spring 事实，不用政策文本填补缺失事实。
- `INSUFFICIENT_INFORMATION`：明确说明现有资料不足，可提出必要追问；不能同时给出无来源规则结论或补偿承诺。不是供应商 refusal、解析失败或无匹配检索的别名。
- 有检索/供应商故障、结构失败、引用不符或知识冲突时保留受控失败，按既有有限重试/修正规则处理；不把失败标成合法不足。HUMAN 辅助不改变处理模式，不阻碍人工继续编辑。
- 没有单条引文 24 字符限制，不追改旧实验合同；引用必须来自本次授权结果，逐字引文须能在 canonical 片段中核实。已有人工 composer 的 2000 字限制继续适用，最终回答/引用总体上限另在执行协议冻结，不用任意截断伪造合规。
- 生成后仍先由 Spring 复核当前 session/ticket/assignment、请求身份、引用和内容；只显示授权结果。客服编辑并显式审阅后才移交人工发送区，最终发送权限/幂等链路不变。

## 本轮独立实现

自有 `supportAssistanceState.ts` 将检索无匹配作为 `noMatch` 中间事件（UI `empty`），不再当回答终态；它允许同 request 的生成结果随后完成。`insufficient` 是独立的回答终态，携带 requestId、说明与可选追问，与 `ready` 有依据回答及 `error` 失败分开。结果仍匹配当前 assignment/requestId/type，撤权清屏规则不变。

面板明确显示“暂无匹配片段，尚未形成回答充分性判断”；只有获复核的生成不足结果才显示“资料不足”。不足说明不会自动填入草稿、发送或改变模式，人工仍可编辑。格式失败单独显示，不冒充不足；长于 24 字符的合成引用完整展示。组件 props 不是模型输出解析器或服务端权限证明。

`agent/src/baseline_agent/support_assistance_evaluation.py` 是 #170 路径专用的纯统计函数，没有 CLI、网络、模型、文件读取、共享检索 DTO 或通用评测/日志框架。冻结标签映射和逐题观测作为参数传入，缺失样本以 NOT_ASSESSED 保留，重复/未知 ID 快速失败，不能仅传成功题重新生成分母。输入检查结果来自独立校验/标注，不能取模型自称“结构/引用/语义通过”。

## 三项检查及拒答计数

| 项目 | 检查内容与完整分母 |
| --- | --- |
| 结构合法性 | 实际回答合同的判定字段/正文/引用结构完整且匹配；解析失败记结构失败。所有冻结题分别记 passed/failed/notAssessed，分母不变。 |
| 引用真实性 | 本请求授权 Top-5 归属、当前有效版本/范围、真实标识与逐字引文；资料不足可以没有引用，无引用不是跳过有效性检查。结构或引用通过不说明语义充分。 |
| 语义充分性 | 独立标注回答是否得到授权资料/事实支持、拒答是否合理，是否混入无依据个案结论；可回答题被拒答也必须保留并记语义失败。模型自报决定不能自证语义正确。 |

正常拒答仅限检索、模型和解析成功（`completed`）、结构合法、引用校验合法、判定为 `INSUFFICIENT_INFORMATION` 且确实说明不足。检索空列表本身不产生回答观测；检索失败、供应商失败、格式失败单列，不计正确拒答。

- 正确拒答必须同时属于冻结无答案题、符合上述正常拒答条件，且独立语义校验通过。无答案标签不能把夹带无依据结论或尚未复核的不足回答变成正确结果。
- 拒答 precision = 正确拒答数量 / 全部正常拒答，目标 **≥ 0.90**。这里正常拒答表示调用和结构合法的明确不足输出；其中语义失败或未评估者仍保留在分母，不计正确分子。实际可回答题上的错误拒答也不能从分母删除。
- 拒答 recall = 正确拒答数量 / **完整冻结无答案题数**，目标 **≥ 0.85**。失败、缺失或尚未运行的无答案题不会从该分母删除。
- 分母为零的指标记 null/未定义，不冒充 100%；分别报告总样本数、已观测数、缺失 ID、故障类别及三项校验的通过/失败/未评估数。
- 函数只给 `refusalTargetsMet` 和 `allSamplesValidated`，不返回整个 RAG 或本票 PASS。即使拒答两个数达标，只要其他题失败、缺失、未评估或语义错误，都不能宣称整体通过；真实 DeepSeek 运行与工程证据仍需独立验收。
