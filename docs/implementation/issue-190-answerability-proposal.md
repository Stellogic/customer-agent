# Issue #190 最小可回答性改进提案

日期：2026-08-31。关联 [Issue #190](https://github.com/Stellogic/customer-agent/issues/190) / [PR #203](https://github.com/Stellogic/customer-agent/pull/203)。研究所依据源码为 `3a5edf6c836ba5358dd9987e550766c3a79711d8`，该阶段运行基线为 `efbdb8348dc9c12f259c69d9e8c16de5e4d3994c`。

**推荐先验证一个固定的小型监督拒答分类器：复用现有检索特征，以 L2 Logistic Regression 学习“当前合法 Top-5 是否提供足够依据”，再在独立校准分区选择唯一决策门槛。** 保留固定 BGE、两路硬过滤、RRF 和 #189 全部冻结资产/标准。离线交叉编码器只保留为第二候选，本轮不同时实施或赛马。

这是研究与待安排的实施方案，不是产品变更、质量通过或运行授权。#165 继续持有窗口；本次未执行测试、格式、依赖生成、模型、校准、冻结评测或锁查询。既有失败报告及唯一参数不改写。

## 为什么选择这一步

现有静态接口已经提供合法向量候选、全文候选及片段，Spring 控制过滤和结果；可回答性判定可放在 RRF 后、返回结果前，接受则原样返回 Top-5，拒绝则返回空结果。无需改检索排序、重建向量协议或新增业务服务。当前方案失败经过保留在[阶段记录](issue-190-stage-20260831.md)，本次不重新打开冻结逐题内容或分数做规则设计。

Selective QA 的一手研究说明，单一模型分数在域迁移下可能不可靠，可以从独立域数据学习拒答判别器；这支持方法类别，**并不证明本文的四特征线性模型在中文检索上有效**。[Kamath 等，ACL 2020](https://aclanthology.org/2020.acl-main.503/)

scikit-learn 将估计分数与决策门槛分开，并明确拟合分类器和选择门槛不能使用同一批数据。[官方阈值选择文档](https://scikit-learn.org/stable/modules/classification_threshold.html) 本方案使用成熟训练实现，限制特征和拟合次数，不自行实现优化器。

| 候选 | 好处 | 实际局限与取舍 |
| --- | --- | --- |
| A：固定检索特征 + L2 Logistic Regression，推荐 | 不新增预训练模型；训练依赖只用于离线开发，运行时可用已固定系数计算；能组合绝对分数、相对分数和两路证据 | 仍是证据充分性的统计代理，不能理解特征未表达的否定、缺失条件或实体关系；小样本跨主题泛化未验证，可能直接失败 |
| B：离线 BGE reranker-base 的 query/passage 分数辅助拒答，暂不采用 | 联合编码问题与段落，能观察更多文本交互；保留原 BGE 与 RRF，不必替代嵌入 | 官方定位是 relevance，不是“包含答案”判定；仍需独立标签和校准。278M 参数、单权重约1.11GB，CPU延迟/峰值内存未验证；新增模型准备、哈希和离线契约成本 |

B 的规格及许可证来源为 [BAAI 模型卡](https://huggingface.co/BAAI/bge-reranker-base)、[官方文件页](https://huggingface.co/BAAI/bge-reranker-base/tree/main)。不能把 logit 或 sigmoid 当作可回答概率；详细一手资料及两候选限制见[方法研究](../research/issue-190-answerability-methods.md)。若未来选择 B，先固定完整 revision、文件清单与许可，再另定同样独立的验证计划；A 失败不自动授权下载 B 或在同一留出集上选择 B。

## A 的固定最小形式（方案值，尚未实现）

标签不是“问题和知识主题相近”，而是“这次检索返回的合法 Top-5 是否覆盖回答问题所需的全部事实”。标注时先按正文给出必要片段和支持事实；训练标签再由固定检索结果与标注确定。语料有答案但必要片段未召回的样本，训练标签为不应返回；质量报告仍算检索失败/有答案拒答，不能靠改标签抹掉召回损失。

只取以下四个通用特征，不包含业务词表、问题ID、条目ID、版本字符串、冻结主题或规则分支：

1. 合法向量候选最高余弦相似度。
2. 第一与第二合法向量候选的相似度差；不足两条时固定为0。
3. 原 RRF Top-5 中，单个片段覆盖查询 CJK 去重词项的最大比例；复用现有固定分析器，查询无词项时为0，不新增停用词表。
4. 两路各自 Top-5 片段ID集合的 Jaccard 一致度；并集为空时为0。ID只用于集合相等比较，不进入学习编码。

这些是基于现有接口和一般检索证据组合的工程假设，不是论文原样配方，也没有使用冻结分数挑选特征。相似度差和词项覆盖都不具有逻辑蕴含含义；同一问题多个正确段落可能使差值很小，因此不用任何单项手写通过规则。

`StandardScaler` 只在训练分区拟合；L2 Logistic Regression 固定 `C=1`、`solver=lbfgs`、带截距、不设类别权重，最多1000次迭代；不收敛则停止，不导出半成品。只拟合一次，不做特征组合或 C 网格搜索。API依据 [LogisticRegression](https://scikit-learn.org/1.7/modules/generated/sklearn.linear_model.LogisticRegression.html) / [StandardScaler](https://scikit-learn.org/1.7/modules/generated/sklearn.preprocessing.StandardScaler.html)。实现前锁定兼容当前 Python 的具体依赖版本与许可，不能随运行漂移；本次未安装或生成锁。

导出特征顺序、训练均值/尺度、系数/截距、唯一门槛、数据及源码哈希、依赖版本和模型协议。Spring 运行时执行相同变换及线性分数比较；训练侧与运行侧的数值一致性须在后续授权窗口验证。不反序列化训练对象，不把 scikit-learn 放入在线服务；分数称为判别分数，不宣称已校准概率。

检索仍先执行权限/发布/当前版本/范围/代次过滤。空候选直接拒答；模型、索引、策略缺失或契约错误仍停止知识结果，不用分类器放宽权限，不退回无来源回答。原诊断候选和来源可观测性保留。只更换拒答策略，不新增答案生成、消费者或 ONNX 能力。

## 独立开发与真正未见留出

本节是未来数据制作合同，**尚未创建这些数据，更未获得测量结果**。旧48题及其已公开留出组都已见过，只保留历史证据，不充当新的盲测，也不参与本轮拟合/选门槛。

计划12个新主题组，每组24题（12有答案、12无答案），共288题。分为6组训练144题、3组校准72题、3组封存留出72题；问句改写、同一文档、共享规则模板必须随主题组一起划分。主题和正文不得复用 #189 或旧48题；训练/校准/留出的检索语料库也按组分开，避免留出主题文本和分数影响拟合。每组计划至少4篇小文档，使用现有目录分块规则；实际片段数与文本长度在数据封存时记录，不能预报为实测规模。

标注覆盖三类普遍能力：直接事实及低词面重合的改写；同主题但正文没有所问属性/条件；实体或前提不匹配。每主题固定6题直接正例、6题低词面改写正例、6题缺少属性/条件的负例、6题实体/前提不匹配负例。正负样本都含自然问法，不能用特殊句式、长度或“未知”等模板词泄露标签。正例需明确支持事实及必要片段；负例需解释为何所在分区实际合并的整个合法语料库都不足以回答，不能只查单主题正文。不得从冻结失败题改写、替换实体或抽象规则来制作新样本。

留出由新的独立数据作者/审阅者在不接收冻结题、历史逐题报告、模型输出或训练参数的条件下制作；使用不继承本任务历史的上下文。方法制定者和实现者只接收数量、主题隔离声明与文件哈希，在参数及受测源码提交锁定前不阅读留出正文/问句/标签。先由数据审阅者按既定规则检查来源和标注，生成不可变manifest；原文封存在协调指定位置，首次评测后再随报告归档。共享文件系统不是真正的访问控制，这属于流程隔离，需记录谁何时查看；如实现者提前看到内容，诚实标为已见，不能继续声称盲测。

这是不同作者/上下文下的合成数据，不是独立真实用户采样或外部第三方评测。若无法落实独立作者与封存，就不启动所谓“未见留出”评测；先完成这项数据条件，而不是降低隔离要求。数据及预处理划分原则参考 [scikit-learn 数据泄漏说明](https://scikit-learn.org/stable/common_pitfalls.html) 与[分组验证说明](https://scikit-learn.org/stable/modules/cross_validation.html)。

## 固定选择、通过与停止条件

以下是新开发验证的预定条件，不改变 #189；只能在方法确定且协调再次放行后执行。

1. **数据/管线预检：** 独立审阅的数据标注有效；真实同构 PostgreSQL/FTS/pgvector/RRF 路径产生开发特征，不用独立 cosine 小脚本替代实际检索。分数和词项计算与在线实现一致；权限等非法候选继续在特征前排除。
2. **一次拟合：** 只用144题训练系数/尺度。校准和留出不得参与拟合、特征选择或归一化。报告训练标签类别数；若没有两个类别或不收敛则停止。
3. **一次选门槛：** 只用72题校准分区，候选为排序去重后的有限决策分数相邻中点，另加最小分数及最大分数向正无穷方向相邻的可表示浮点数（覆盖全接受/全拒绝）；接受条件固定为分数大于等于门槛。筛选满足下表所有质量条件的门槛，再依次最大化 answered Recall@5、无答案precision、门槛值，唯一确定并先提交参数/源码/报告。若无可行门槛，报告不可行，**不取最接近值进入留出或冻结门**。
4. **一次未见留出：** 独立运行者用已提交的同一参数和代码评测72题；所有下表条件同时通过才可申请冻结验收。先报告整体、各主题和已预定问题类型分项结果及分子/分母，不做看结果后的删题。72题只是有限合成样本，不足以证明真实场景概率保证。
5. **原冻结门：** 仅在独立留出通过和协调授权后，对已锁定方法运行 #189 一次。全部原标准仍需通过；实际浏览器、双轴CR及最终完整门禁仍必须另行完成。任一步 FAIL 就保存失败、停止该轮，不自动换候选 B，不继续扫参数或循环冻结评测。

| 质量条件 | 校准与新留出预定要求 | 含义 |
| --- | ---: | --- |
| answered Recall@5 | ≥0.90 | 拒答后的必要片段召回，不能报拒答前候选召回替代 |
| answered MRR@5 | ≥0.75 | 沿用既有指标定义，固定RRF顺序 |
| 无答案precision | ≥0.90 | 真无答案且拒答 / 全部拒答；分母为0按未通过，不记1 |
| 无答案recall | ≥0.85 | 真无答案且拒答 / 所有无答案 |
| 非法候选进入结果 | 0 | 独立权限/版本/范围回归检查必须零违规，不能用288题内容集代替这些检查 |

无答案precision依赖数据中无答案比例，均衡开发集通过不保证业务或冻结分布通过，必须并列报告有答案误拒率与无答案误接纳率。旧策略只可作为事先固定的独立数据比较基线，复用同一次检索输出；不重选旧参数，不根据留出对比决定换模型。训练集、校准集、留出集及冻结集的角色和每次访问/运行次数均记录在报告。

## 重复查看冻结验收集的偏差控制

本任务已看过冻结实测与失败分析；因此不能声称原 #189 集仍是研究者未见的测试集。即使没有直接调它的阈值，方法方向也可能被历史反馈间接影响。新的流程只能减少继续泄漏，不能消除既有认知或恢复“首次盲测”资格。[官方说明：用测试反馈改模型会造成泄漏](https://scikit-learn.org/stable/modules/cross_validation.html)

- 从本提案开始，不再读取冻结问题、逐题分数、命中ID或重打分；历史原报告只作交付证据保存。方案、特征、阈值选择目标和数据分组先提交，之后不凭冻结反馈变更。
- 新留出保持封存，检索和标签审阅不向方法作者透露结果；只对一个预定候选和一组参数做一次正式测量。留出一经打开即记为已见，失败后不能复用它选择下一方法。
- #189继续承担不可变的合同验收，新的未见留出承担补充泛化证据；任何一个通过都不替代另一个。所有尝试和FAIL保留，不只展示最后一次PASS。
- 确认的执行缺陷可以在后续授权下修复，但必须写明源码差异、受影响证据和复验原因；重复运行照实计数，不把规则/方法变更伪装成执行修复。不自动重写冻结基线或建立新的低门槛。

## 成本、边界与下一步

候选A：本次仅文档，付费模型API调用0元。未来保持本地固定BGE，不需新增预训练权重；新增成本是288题合成与独立标注复核、真实开发检索、一次小型分类器拟合和一次留出测量。包下载量、宿主时长、内存及人工耗时尚未采集，不把上次48/64题耗时线性外推为承诺。通过同一次正常运行记录源SHA/base、RunId、数据/参数哈希、环境、分项耗时与费用，不为简历加压测。

候选B若以后获选，新增约1.11GB权重与每查询最多5个query/passage联合编码；CPU可用性不等于满足交互延迟，必须先单独核定资源预算。不是付费API方案，但本轮无下载/实施授权，不占用 #168 的消融/ONNX范围。

推荐确定A作为**一次有停止条件的可行性验证**，不是承诺A一定解决问题。方法确定后才能安排数据制作、静态实现/双轴审查，再由协调分配运行窗口；当前无需用户逐项批准，但不会把研究授权扩成产品或运行授权。若独立校准已不可行，最小下一步是基于独立开发证据重新决定是否承担B的新模型成本或调整方法范围，而非继续动A的阈值。没有新测量，本提案无新的收益或质量指标；Agent生成研究不等于用户亲自实施。
