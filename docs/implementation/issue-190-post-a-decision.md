## 最小产品接缝与必须确认的边界

以下均为待批准方案，不是现有已实现行为。

1. 保留固定离线BGE、全文/pgvector前置硬过滤、候选数量及RRF。Spring只将本次授权且当前版本的Top-5正文、问题与临时片段编号交给私有Agent判定；不给全库、身份、期望答案、标签或评测分数。空候选/无权限仍由Spring本地处理，不付费询问模型。
2. 固定 `deepseek-v4-flash`、非思考模式、一个提示与严格JSON schema：`sufficient`和来自本次片段的引用ID/短原文。不给工具、不执行知识正文指令、不输出补偿建议或业务答案。引用成员/原文匹配只核对来源，不能替代语义充分性验证。接受则返回原RRF Top-5，拒绝则返回空结果，不改排序。
3. 超时、余额/鉴权/供应商故障、无效结构、截断或错误引用记运行错误并停；不得记为正确拒答或改用旧A/假模型。请求与返回model、可得fingerprint、提示/schema哈希、usage和失败类型留证；别名或fingerprint变化则停止跨阶段比较，不能重跑挑结果。供应商未提供固定快照的限制需明确接受。[Responses接口](https://api-docs.deepseek.com/api/create-response/)、[版本记录](https://api-docs.deepseek.com/updates/)
4. 可复用现有 `deepseek_investigation_model.py` 的Responses传输/结构化输出经验及调用证据形状，但其延迟补偿prompt/schema不能拿来判知识充分性，已有重试次数不能照搬。需一个小的专用调用，不新建通用模型框架。Spring保持授权权威；外部调用不长时间占用DB事务，发布前复核授权和知识代次，变化则报错，不自动再花钱重查。
5. 当前 `KnowledgeRetrievalPolicy` 是数值threshold与校准哈希形状。C需真实的方法/提示版本元数据，不伪造0.5阈值或校准哈希。保留现有查询/来源/results语义；如需协议兼容调整，先限定批准范围，不能借此改#189题、期望、指标或通过门槛。真实UI须明确提交才触发调用，禁止隐式重试增加费用；研究回放不替代这一产品集成验证。

**需要协调明确确认的变更**：#190“本地CPU/离线”是否允许新增联网充分性判定及服务不可用时检索失败；哪些问题/知识正文可外发；能否接受云模型不能固定权重SHA；策略元数据的兼容演进。既有DeepSeek调用权不等于所有内部知识均获外发许可。首次只考虑明确可外发的合成材料，真实内部资料默认不获许可。#168/#169/#170仍阻塞，C也不提前接入调查消费链。

## 一次验证设计：批准后才可封存并运行

**不训练、不扫描阈值、不搜索提示词。** 在任何调用前提交固定实现、一个通用充分性提示、schema、模型/模式、预算与停止条件。提示仅来自任务定义和上述方法，不从具体失败问句提取关键词或领域例外。开发反馈后不修提示重试；确定的传输/接缝缺陷保留原失败，是否允许修复重验由协调另判，不能假称算法尚未运行。

- **已见开发检查：最多72次。** 使用当前校准72题及保存的合法Top-5作固定上下文回放，仅验证C的有限可行性。该分区在A中已看过，必须标“已见开发回放”，不再称校准或未见评估，不据结果调整提示/模型。训练144题仅用于本次静态归因，不另付费重跑。完整分区纳入，不删除难题；已存支持关系用于离线计分，不送入模型。
- **独立验证：最多另72次，需另放行。** 仅开发通过才冻结源码/提示/报告SHA，交由独立运行者测未见数据。现有72题seal继续关闭，本任务不查位置、不看内容。是否把该未使用seal用于C，须协调确认其原封存用途与新协议兼容；不兼容则由无历史作者/审阅者重新独立封存，不能由实施者改题。只接收约定元数据，题目不参与路线选择。
- **通过条件不变**：对各完整分区，拒答后answered Recall@5≥0.90、MRR@5≥0.75、unanswered precision≥0.90、recall≥0.85；任何越权/错版本/不适用命中为0，任何运行/结构/预算错误先判运行失败，不能算拒答。静态回放不能证明权限安全，进入独立产品运行前必须另有真实Spring硬过滤/代次一致性验证。独立阶段还需产品与固定判定路径一致；报告分子/分母、分主题/类型描述和错误数，不事后新增放宽规则。
- **停止**：开发或独立阶段任一质量条件失败即结束C这一轮，不换提示、模型、数据或改方法重选；供应商/余额/版本/预算失败同样停，保留未执行项。成功也仅是可行性证据，不是交付；#189原冻结质量门、真实UI和最终完整本地门禁仍需另行协调，不能本轮启动或解阻下游。

偏差控制：当前训练/校准已见，且实施历史曾反复查看#189，无法靠再次称“冻结”恢复盲性。故开发通过只是准入，未见独立验证必须由不同运行者执行且仅一次；不拿其结果作方案赛马。#189维持原始资产/门槛作为兼容验收，不冒称它仍是对实施者的盲测。本文归因只用开发归档的聚合值，没有为此打开冻结题或留出。
