## What to build

作为纯验收票，在确定性模型配置下通过单一最高层产品接缝验证 #149：真实 Chromium 访问生产构建 React，经 Spring API/SSE、真实 PostgreSQL 与真实 LangGraph 覆盖受理、多工单、多轮会话、人工处理、补偿、RAG、权限和高保真 UI。

## Acceptance criteria

- [ ] 本票只增加最高层验收场景、运行门禁和证据文档，不实现或重构跨模块产品功能。
- [ ] 发现功能缺口时明确阻塞本票并回到对应实施票修复，不在验收 PR 中顺手补做。
- [ ] 主场景覆盖自然语言受理同订单多个问题、一次确认建单、并行处理、客户追加消息和旧代次围栏。
- [ ] 主场景覆盖真实流式输出、断线恢复、事实充分、有依据回复、五分钟自动解决和七十二小时重开。
- [ ] 跨角色场景覆盖受理协助、持久化客服领取、人工回复、标准补偿、订单级额度并发、审批和撤权。
- [ ] RAG 场景覆盖客户引用、客服辅助、无答案、错误版本、知识冲突和检索失败。
- [ ] UI 场景覆盖桌面、窄屏、关键 loading/empty/error、状态画廊及“开发中”不产生业务成功。
- [ ] 安全场景证明模型密钥、Embedding 权重或路径、Agent 地址、数据库 URI、prompt、reasoning、原始工具载荷和 checkpoint 不进入浏览器或产品日志。
- [ ] 使用唯一隔离 Compose project、镜像 tag、端口和卷，运行完整规范化门禁并保存可复核证据。
- [ ] 验收通过只证明确定性模型配置下的完整产品契约，不冒充真实 DeepSeek 证明。
