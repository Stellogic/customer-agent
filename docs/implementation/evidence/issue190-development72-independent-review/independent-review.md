# development72 独立静态语义审阅

本意见仅依据 `packet.json` 内完整 18 个 corpus 片段及 72 个问题各自固定 Top5，未读取其他标签、映射、模型输出、历史报告、实现或留出集，未联网或运行测试、构建、评测、锁操作。这是独立 Agent 的静态语义意见，不是人工金标、模型运行结果或盲测通过声明。

## 判定口径

- `corpusAnswerable`：完整 corpus 是否足以回答问题的全部所求。
- `top5Sufficient`：仅该题固定 Top5 是否足以回答全部所求；不会借用 Top5 外片段补足。
- `YES` 表示完整支持；`NO` 表示存在明确缺口，不表示问题前提必然为假；`UNCERTAIN` 表示问题措辞存在会改变充分性结论的实质解释空间。
- 接受正常语义等价及明确文本蕴含，如“纵线／经线”“纸模板／纸样”“基础交错纹／平纹”。不把不同材料、制品、仪器或工艺的规定自动迁移，也不从相近数值推算缺少参数的答案。
- 下表的 corpus ID 和 Top5 编号指向支持事实或最相关但不足的事实；对 `NO` 不把“相关”当成“支持”。完整 corpus 已逐项核对，未列出的片段不提供缺失事实。`#n` 是该题包内的 `chunk` 编号。
- 对常规操作问法，按问题明确要求的步骤粒度判断，不额外要求语料没有被问到的技术细节。
