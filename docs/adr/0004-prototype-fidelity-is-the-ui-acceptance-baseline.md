# 高保真原型作为正式 UI 验收基线

正式 React 应用尽可能复刻 `前端原型/stellogic-prototype-package` 已覆盖的页面、布局、信息层级、状态和交互，而不是另建与正式产品分离的静态 Demo。客户与内部工作台都先按订单分组展示工单；一次创建多张工单后先进入订单总览，总览显示各工单的独立 Agent 状态和待客户事项，再进入对应工单对话。正常业务页面使用权威合成数据；暂未接通但对产品有帮助的入口保留完整 UI，并在操作时明确反馈“开发中”，但不得伪造发送、审批、知识发布、补偿或其他业务成功。只有用户明确要求、当前领域模型变化或授权边界冲突时才偏离原型；不便实时制造的状态可以在明确标注的状态画廊中使用固定展示数据。
