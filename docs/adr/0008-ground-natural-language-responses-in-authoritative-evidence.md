# 自然语言回复必须基于权威依据

Agent 不受少数固定答复模板限制，可以结合多轮上下文自然组织表达，但业务事实必须来自授权调查工具，规则说明必须关联有版本的知识条目，金额、资格和时效承诺只能使用 Spring 返回的权威结构化结果。发送前检查越权承诺、无依据事实和敏感信息；一次受控修正后仍不安全，或唯一对话模型 DeepSeek、工具和知识检索经过有限重试仍失败时，停止当前运行、保留已完成步骤、向客户显示安全的暂时不可用提示并转人工。内部人员可以看到受控失败分类，但系统不静默切换模型、不伪造工具结果，也不回退成假装完成的固定答案。完整消息是权威记录，Agent 使用近期消息、可重建的工作摘要、调查事实和知识引用控制上下文规模。内部可观察性保存结构化调查步骤、工具类型、动作结果、证据与知识引用和受控理由码，不保存或展示逐字模型推理、系统提示词和原始工具载荷。
