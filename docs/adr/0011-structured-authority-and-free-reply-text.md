# 结构化业务权威与自由回复正文分离

用户于2026-09-08通过职责对齐明确确认：Spring只做最少且必要、具有确定规则的核对；模型自由正文不通过关键词、正则或语义判断阻断。该决定局部替代[ADR 0008](./0008-ground-natural-language-responses-in-authoritative-evidence.md)的正文语义拦截要求，保留基于权威事实写作的模型指导，以及[ADR 0010](./0010-deterministic-required-facts-and-evidence.md)的事实与权限边界。

Spring继续校验协议结构、明确规定的枚举或确定输出、工单与证据归属、来源及版本、结构化事实、金额、审批、执行及有效代次。自由正文仅受非空和长度等传输约束；正文中的订单字样、金额、“已退款”“已关闭”等不作为拒绝依据，也绝不作为执行退款或改变工单状态的权威输入。Agent不重复进行正文语义拦截。知识引用仍须来自授权来源、正确版本和实际引文，知识正文不进行语义阻断。

普通回复通过必要核对后直接发送，不新增逐条人工正文审批。既有补偿审批、客户要求人工及调查无法继续时的接管路径保持。自由正文可能有错误陈述，这不等于结构化事实或业务执行失控，也不宣称自动识别所有幻觉。放弃有限词汇白名单与逐句语义审核，以减少学习项目的误拒和复杂度；真实验收仍诚实记录模型表现，不将安全转人工冒充自动调查成功。

决定记录见[职责对齐](../delivery/spring-responsibility-alignment.md)。
