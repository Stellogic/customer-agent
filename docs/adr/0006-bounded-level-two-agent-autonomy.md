# 采用受控的 L2 Agent 自治

Agent 可以基于客户自然语言自主识别问题、决定调查路径和证据组合、开展多轮公开沟通、调用授权的只读调查与知识检索能力、提出澄清、推进等待状态、创建标准补偿提案并转人工。Spring 不预先编排完整调查流程，而是校验证据权限、来源、时效、冲突和风险场景不可缺失事实。只有白名单低风险场景中事实充分、已给出明确结论、无待办动作且无待审批补偿的工单，才可在客户五分钟无回复并经 Spring 重新校验后由 Agent 自动解决。Agent 不得修改地址、取消订单、批准或执行补偿、执行退款、发放权益、覆盖 Spring 的资格或金额计算，也不得在人工处理模式下直接联系客户。Spring 继续承担身份、事实、授权、状态转换、补偿政策和副作用的业务权威；相比只允许模型选择几乎确定的动作，这一边界扩大认知与编排空间，同时保留不可逆操作的确定性控制。
