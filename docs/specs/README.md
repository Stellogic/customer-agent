# 历史规格索引

本目录保存 GitHub Issues 中已经形成的规格正文镜像，便于在仓库内检索、评审和随代码版本留档。

## 同步范围

- 包含标题以 `[规格]` 开头的所有 GitHub Issue，不区分 `OPEN` 或 `CLOSED`。
- 镜像 Issue 正文，不合并评论、实施票据、Wayfinder 调研或原型记录。
- GitHub Issue 仍是规格事实源；本目录是按日期生成的仓库内快照。
